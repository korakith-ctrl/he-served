# ข้อควรรู้ก่อนใช้เป็นหลักฐานทางกฎหมาย

เคลียร์กันออกแบบมาเพื่อบันทึกข้อตกลงและเหตุการณ์ระหว่างเจ้าหนี้กับลูกหนี้ ไม่ใช่บริการให้คำปรึกษากฎหมาย และไม่สามารถรับรองผลของคดีหรือการบังคับชำระหนี้ได้

ระบบบันทึกข้อมูลต่อไปนี้เพื่อช่วยเพิ่มความน่าเชื่อถือของหลักฐาน:

- ชื่อ อีเมล Firebase UID และผู้ให้บริการที่ใช้เข้าสู่ระบบ
- ข้อความข้อตกลง เวอร์ชัน และ SHA-256 digest ของข้อมูลแต่ละเวอร์ชัน
- การกดยอมรับอย่างชัดแจ้งของแต่ละฝ่ายพร้อมวันเวลา
- หลักฐานการโอน รายการรับชำระ ข้อพิพาท คำขอแก้ไข และ audit log
- การยอมรับจากอีกฝ่ายสำหรับการเปลี่ยนแปลงสำคัญหลังเริ่มข้อตกลง

ก่อนใช้กับหนี้จริงควรตรวจสอบอย่างน้อย:

1. ชื่อคู่สัญญาควรเป็นชื่อจริงและบัญชีเข้าสู่ระบบควรเป็นของบุคคลนั้นจริง ระบบนี้ยังไม่ได้ยืนยันตัวตนด้วยบัตรประชาชนหรือ Digital ID
2. เก็บหลักฐานการส่งมอบเงินหรือทรัพย์ หลักฐานสนทนา และรายการเดินบัญชีไว้ด้วย เพราะการยอมรับยอดในแอปไม่พิสูจน์การส่งมอบเงินทุกกรณี
3. ตรวจอัตราดอกเบี้ย เบี้ยปรับ ค่าธรรมเนียม และเงื่อนไขทั้งหมดกับกฎหมายที่ใช้บังคับ ระบบไม่ได้คำนวณดอกเบี้ยให้อัตโนมัติ
4. ตรวจข้อกำหนดเรื่องหลักฐานเป็นหนังสือ ลายมือชื่อ และอากรแสตมป์ตามชนิดและมูลค่าของสัญญา
5. ส่งออก JSON หลังเหตุการณ์สำคัญและเก็บสำเนาในที่ปลอดภัย SHA-256 digest ช่วยตรวจความสอดคล้องของ snapshot แต่ไม่ใช่ตราประทับเวลาอิสระจากผู้ให้บริการที่เชื่อถือได้
6. หากมูลค่าสูงหรือคาดว่าอาจมีข้อพิพาท ควรให้ทนายไทยตรวจสัญญา และพิจารณาใช้บริการลายมือชื่ออิเล็กทรอนิกส์/Digital ID ที่ยืนยันตัวตนได้เข้มแข็งกว่า
